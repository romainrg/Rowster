# Rowster 0.1 — manual tests

What the automated tests cannot check: anything that shows a system prompt, needs a real pointer, or needs a server that is not on this Mac. Run them on a Debug build (`make run`) unless a step says otherwise. Never against a production database.

Local servers for the steps that need one: `scripts/integration-servers.sh start` (PostgreSQL on 54329, MySQL on 33069, MariaDB on 33079, sshd on 22229; user `rowster`, password `rowster-test`, database `rowster_test`).

## Launch and windows

- [ ] `make demo`: the welcome window lists six connections in two groups; nothing asks for a permission.
- [ ] Double-click a demo connection: a work window opens; a second connection opens a second window.
- [ ] Close and reopen the app: the welcome window comes back; no window connects by surprise to a server you did not open.
- [ ] System language set to French: the whole interface is in French.

## Keychain

- [ ] Create a PostgreSQL connection to the local server with *Save in Keychain*, Test, Save: no error, the password is in Keychain Access under `io.github.romainrg.Rowster`.
- [ ] Open the connection: it connects without asking again.
- [ ] Rebuild the app (`make build`) and open the connection: macOS asks to allow access to the Keychain item. Expected with an ad hoc signature.
- [ ] Edit the connection, leave the password field empty, Save: the saved password is kept.
- [ ] Switch it to *Ask every time*: the item disappears from the Keychain, and opening the connection shows the password prompt.
- [ ] Delete the connection: its Keychain item is gone.
- [ ] `~/Library/Application Support/Rowster/connections.json` contains no password.

## Connecting

- [ ] Paste `postgres://rowster:rowster-test@127.0.0.1:54329/rowster_test?sslmode=require` in the URL field: the form fills, the password goes to the password field, and the URL field no longer shows it.
- [ ] Local network prompt: connect to a database on another machine of the LAN (macOS 15 or later). The system asks once, with Rowster's explanation.
- [ ] TLS *Verify identity* against a server with a real certificate succeeds; against the local self-signed server it fails with a TLS error.
- [ ] MySQL and MariaDB local servers: connect, browse, edit and commit a row.
- [ ] SQLite: drop a `.sqlite` file on the form; open it; a file that is not a database gives a clear error.

## SSH tunnel

- [ ] Connection through the local sshd (host `127.0.0.1`, port 22229, identity `build/integration/ssh/id_ed25519`): on first use Rowster shows the host-key question; answer Yes; the connection opens.
- [ ] Same with `id_passphrase`: Rowster asks for the passphrase (`rowster-test`) in its own dialog; a wrong passphrase is asked again; Cancel fails the connection cleanly.
- [ ] A real bastion from `~/.ssh/config`, with ProxyJump and the 1Password or Secretive agent: one authorization, then the sidebar, a page of data and Cancel all work.
- [ ] Database TLS *Required* through the tunnel.
- [ ] Close the window: no `ssh` process of Rowster remains (`pgrep -fl "ssh -N"`).
- [ ] Kill the `ssh` process while the window is open, then reload a table: the tunnel and the connection come back.

## Safety

- [ ] A connection labelled *production* opens with the lock; editing a cell, adding a row and running `UPDATE` in the editor are all refused with an explanation.
- [ ] In its editor, `SET SESSION CHARACTERISTICS AS TRANSACTION READ WRITE` is refused.
- [ ] *Unlock writing*: the confirmation appears; after it, an edit can be committed. Click the lock: writing is refused again.
- [ ] Settings > *Require Touch ID to unlock writing*: unlocking now shows Touch ID; cancelling it leaves the window locked.
- [ ] `DELETE FROM some_table` in the editor shows the statement and waits; Cancel is the default button; nothing was deleted.
- [ ] *Run All* with two destructive statements shows both before anything runs.

## Data grid

- [ ] A table with at least 100,000 rows and 30 columns, page size 5,000: flinging through the page stays smooth.
- [ ] Sort by two columns with shift-click, close the tab, reopen the table: the sort and the column widths are back.
- [ ] Hover the arrow of a foreign-key cell for a moment: the referenced row appears; moving away closes it; clicking opens the referenced table filtered on the key.
- [ ] A BLOB cell shows a size; the inspector's *Load* shows an image or a hex dump.
- [ ] ⌘C on one cell, then on several rows; *Copy Rows As* each format pastes correctly in a text editor.
- [ ] Double-click a cell, type, Return: the cell is highlighted; Escape while editing leaves it unchanged.
- [ ] Add a row, delete a row, ⇧⌘P shows the three statements, ⌘S commits; the page reloads with the changes.
- [ ] Make a commit fail (a duplicate key): the error is shown, nothing changed in the database, the changes are still pending.
- [ ] Export a filtered table to CSV and to JSON; cancel a long export.

## Editor

- [ ] Typing does not turn quotes into curly quotes or `--` into a dash; ⌘F opens the find bar; ⌘Z undoes.
- [ ] ⌘↩ runs the statement under the cursor (shaded); with a selection it runs the selection; ⇧⌘↩ runs all.
- [ ] `SELECT pg_sleep(30)` (PostgreSQL) or `SELECT SLEEP(30)` (MySQL): the toolbar shows Cancel; clicking it ends the statement within a second and the tab is usable again.
- [ ] A result larger than the limit shows *Load More*.
- [ ] History lists the statements of this connection only; a statement with `PASSWORD 'x'` is stored as `'***'`; *Clear History* empties it.

## Release build

- [ ] `make release`, open the DMG, drag the app to Applications, open it through *Open Anyway*.
- [ ] In that build, an SSH connection with a passphrase still shows Rowster's prompt (the app is its own askpass helper).
